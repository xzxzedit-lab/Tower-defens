# Архитектура — записи решений

## 2026-11-19 — этапы 1–2
- **Скрипты:** классические `<script>` + `PD`; порядок: pd → data/* → save → economy → enemies → towers → waves → physics → game → renderer → input → ui → main.
- **Разрешение:** 640×384, тайл 32 (раньше 800×480/40). Числа прототипа (радиусы, скорости) умножены на 0.8; пути заданы в тайлах без изменений.
- **Время:** фиксированный шаг 1/60; ускорение 1x/2x/3x = больше шагов за кадр.
- **Цель башни:** враг в радиусе с наибольшей пройденной дистанцией (`dist`).
- **Пулы:** `PD.Pool` для врагов и снарядов; снаряд хранит `target` + `tid`, чтобы не попасть в переиспользованный объект.
- **Боссы:** `waves % bossEvery === 0` или финальная волна карты; один босс, появляется последним.
- **Решения автора:** боссы каждые 10 волн + финальный на волне 15 карты 1; значок сердца в карточках башен = дальность атаки; строить и улучшать можно во время волны.
- **Сохранение:** ключ `pixel_defenders_save`, `schemaVersion: 1`; хранит пройденные карты, лучшую волну, число убийств, скорость. Прогресс внутри забега не сохраняется.
- **Экономика:** числа прототипа сохранены (12/35 за врага, +25 за волну, улучшение 40); продажа 70% — новое. Пересмотр цен — задача `game-economy`.

## 2026-11-19 — этап 3 (графика)
- **Спрайты:** `tools/build_sprites.py` рисует всё кодом (Pillow): общая палитра, автоподсветка сверху-слева, тень снизу-справа, тёмный контур. Результат: один атлас `assets/sprites/atlas.png` и `atlas.js` (`PD.atlas`: кадры и анимации). `atlas.js` — скрипт, а не JSON, потому что `fetch` с `file://` не работает.
- **Размеры:** башни 32×40, враги 24×24, босс 40×40, снаряды 9×9, тайлы 32×32.
- **Анимации:** время игровое (`state.time`), пауза замораживает. Враги: 4 кадра, 8 fps, отдельные кадры для взгляда влево. Башни: покой 2 кадра, атака 0.22 с после выстрела (`tower.fired`).
- **Эффекты:** `PD.VFX`, пул до 60 штук; сейчас попадание и дымок смерти (взрыв, лёд, яд в атласе есть, ждут башен).
- **Запасной режим:** если атлас не загрузился, рисуются прямоугольники.
- **Декор:** `map.decor` блокирует клетки (`state.blocked`).
